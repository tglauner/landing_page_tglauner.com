Public MCP Server

Currently in active development. The public MCP server exposes Tim Glauner's profile as a tool and resource for MCP-enabled assistants and apps.

What it is

Streamable HTTP MCP endpoint with read-only profile data for quick, structured context.

  • Tool: profile returns a summary plus JSON.
  • Resource: profile.json returns Schema.org Person data.
  • Transport: Streamable HTTP at /mcp.

How to connect

Point any MCP client at the endpoint below. For a quick test, use the MCP Inspector.

Endpoint https://mcp.tglauner.com/mcp 
npx -y @modelcontextprotocol/inspector https://mcp.tglauner.com/mcp
